# Security

TenantProof is pre-v0.1.0. No released version is supported for production
use, and the npm package is private and unpublished. Security fixes land on
`main`.

## Reporting a vulnerability

Please report vulnerabilities privately. Give the maintainer time to
understand and fix the issue before any public discussion.

If [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
is enabled for this repository, use GitHub's report form:

<https://github.com/Miki0195/tenantproof/security/advisories/new>

You can also open the repository **Security** tab and choose **Report a
vulnerability**. That form stays private between you and the maintainers.
It is available only after a maintainer enables private vulnerability
reporting in the repository settings.

If that page is not available, email `buchsbaum.miki2004@gmail.com`. Until that
address is set, do not send the report to a public issue, discussion, or
pull request.

In the report, include:

- what the problem is, and what an attacker could do with it
- the file, workflow, or dependency involved
- the commit you tested
- the steps a maintainer can follow to see it

Include only the detail needed to reproduce and fix the issue.

There is no bug bounty, and there is no promised response time. The
maintainer will acknowledge the report when they can, and will agree on a
fix before discussing it in public.
