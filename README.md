# TenantProof

TenantProof is an early-stage, open-source CLI for testing
explicit HTTP API authorization expectations.
Status: pre-v0.1.0, not ready for production use.
Scope: local-first, GET/HEAD checks, test credentials only.
The first release will offer a YAML policy, terminal output,
redacted JSON results and a runnable local example.
